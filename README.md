# OTUS-JS-PRO-LeetCode

В данном репозитории представлена реализация проекта **"LeetCode"**, выполняемая в рамках курса JS-Pro платформы онлайн-образования "Otus".

## На данный момент реализовано:
1. Спроектирован API.
2. Реализовано взаимодействие контроллеров с базой данных, через сервисы и реппозитории.
3. Подготовлена конфигурация для деплоя проекта с использованием Docker.



## Запуск
1. Запустить приложение: `npm run start:dev`

##  Запуск приложения с использованием Docker
Для запуска приложения с использование docker используется система оркестрации docker compose, так как необходимо запустить и связать 2 контейнера (1-й - само приложение, 2-й БД Postgresql).
Чтобы запустить приложение, ипользуйте команду `docker compose up -d`
После этого, можно перейти по адресу localhost:80/api для тестирования
